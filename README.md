# Quiz Copilot

Браузерное расширение (Chrome/Edge, Manifest V3): находит вопросы теста на странице, отправляет их в локальную или облачную LLM (OpenAI-совместимый API) и рисует ответы бейджами прямо над вариантами. Умеет кликать правильные варианты само, если включён автовыбор.

Без сборки, без зависимостей — чистый JS.

## Установка

1. Открой `chrome://extensions` и включи **Режим разработчика**.
2. **Загрузить распакованное расширение** → выбери папку `quiz-copilot`.

## Настройка модели

**Локально (LM Studio / Ollama):**
1. Запусти сервер в LM Studio (**Developer → Start Server**) и загрузи чат-модель.
2. В попапе нажми **«Проверить связь»** — расширение само переберёт `localhost`/`127.0.0.1` и стандартные порты (`1234`, `11434`, `8080` и т.д.) и подхватит загруженную чат-модель.

**Облако:**
В настройках попапа есть пресеты (Gemini, GitHub Models, DeepSeek, Mistral, OpenRouter, Groq, Cerebras). Выбираешь провайдера, вставляешь свой API-ключ и жмёшь **«Проверить связь»**.

## Как пользоваться

- `Alt+Q` или тумблер в попапе — вкл/выкл.
- Над вариантами появляются бейджи (**✓** или **?** при низкой уверенности), клик по бейджу выбирает вариант.
- **Автовыбор ответа** — кликает само, если уверенность модели выше выставленного порога.
- **Спросить по выделенному** — быстрый ответ по выделенному тексту в карточке в углу.

Поддерживает обычные `input[type=radio|checkbox]` (в том числе скрытые в кастомных темах), ARIA-виджеты, `<iframe>` и SPA с подгрузкой вопросов, а также кликабельные `div`/`button`-варианты, если на странице нет стандартных инпутов.

Если на сайте вопросы не видны, в попапе есть кнопка **«Диагностика страницы»** (показывает по кадрам, что нашлось в DOM), а в `dev/` лежат `harness.html` и `harness-custom.html` с мок-API для локальной отладки.
